# EarMixer

Два созвона в Яндекс Телемосте одновременно: один звучит в **левом** наушнике, другой в **правом**.

## Запуск

```bash
npm install
npm start
```

## Как пользоваться

1. В каждой половине окна открыт свой Телемост. Вставьте ссылку на встречу (или просто её числовой ID) в поле адреса и нажмите «Открыть» — или зайдите во встречу прямо через интерфейс Телемоста.
2. Кнопками **Левое / Оба / Правое / 🔇** выберите, в какое ухо идёт звук созвона. «Поменять» в шапке меняет уши местами (Ctrl+Shift+S).
3. **Микрофон** — пускать ли ваш голос в этот созвон. Работает поверх кнопки Телемоста, так что можно говорить только в одну встречу (Ctrl+1 / Ctrl+2).
4. **Тест** — короткий сигнал в выбранное ухо, чтобы проверить, правильно ли надеты наушники.
5. Индикатор рядом с громкостью показывает, что звук созвона действительно идёт.
6. В шапке можно выбрать устройство вывода и раскладку (оба созвона / только первый / только второй — звук при этом продолжает идти).

Каждый созвон работает в отдельной сессии, поэтому можно войти в два разных аккаунта Яндекса.

## Как это работает

Electron-приложение с двумя встроенными окнами Телемоста (`WebContentsView`). До загрузки скриптов Телемоста в страницу внедряется перехватчик (`src/call-preload.js`):

- WebRTC-звук, который Телемост проигрывает через `<audio>/<video>` (`srcObject`), забирается в WebAudio, а сам элемент глушится. Для страницы `muted`/`volume` остаются виртуальными, так что кнопки Телемоста работают как обычно.
- Всё, что страница подключает к `AudioContext.destination`, перенаправляется в тот же маршрутизатор.
- Маршрутизатор сводит звук в моно и подаёт его только в левый или только в правый канал (`ChannelMerger`).
- Свойство `enabled` у дорожки микрофона тоже виртуальное: реально дорожка включена, только если её разрешают и Телемост, и EarMixer.

## Ограничения

- Короткие системные звуки Телемоста, проигрываемые по URL (не через WebRTC), могут звучать в обоих ушах.
- Демонстрация экрана на Windows всегда показывает основной монитор.
